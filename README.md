## 🚀 Estado del Proyecto: En Construcción(CARPETA FOTOS)
Este repositorio contiene el código fuente de mi portfolio profesional. Actualmente se encuentra en fase de desarrollo activo y **el despliegue oficial y definitivo en producción (vía Vercel) está programado para el 10 de abril**. 

El objetivo de este proyecto no es solo mostrar mi trabajo, sino servir como una demostración técnica de mis habilidades arquitectónicas en el Frontend, aplicando estándares de la industria y código limpio.

---

## 🛠️ Stack Tecnológico (Nuxt Ecosystem)

El portfolio está construido sobre el ecosistema completo de **Nuxt**, aprovechando su potencia para SSR (Server-Side Rendering) y rendimiento óptimo:

* **Framework Base:** Nuxt & Vue.js.
* **Lógica y Tipado:** TypeScript y JavaScript moderno.
* **Estilos y UI:** Tailwind CSS integrado con SCSS para un control granular del diseño y animaciones.
* **Infraestructura:** Despliegue continuo (CI/CD) configurado con **Vercel** para actualizaciones en tiempo real.

---

## 🧠 Técnicas y Buenas Prácticas Aplicadas

Para garantizar que este proyecto sea escalable y mantenible, he implementado las siguientes metodologías de ingeniería de software:

* **Arquitectura Modular:** Componentes altamente reutilizables y desacoplados.
* **Early Return Pattern:** Optimización de la lógica en funciones y controladores para evitar anidamientos profundos y mejorar la legibilidad.
* **Principios SOLID:** Aplicados en la estructura de los *composables* y la gestión del estado.
* **DRY (Don't Repeat Yourself):** Centralización de variables CSS (SCSS) y configuración de Tailwind para mantener un "Design System" coherente (estética Cyber-Dark).
